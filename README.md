# 📌 Automated Pinterest Affiliate System

An automated engine that finds trending Amazon products, generates photorealistic cozy room photos using free FLUX AI, creates Pinterest SEO descriptions, overlays Google Fonts typography, and deploys mobile-optimized bridge pages with Amazon affiliate tagging.

## Quick Start
```powershell
cd G:\CLI\pinterest-auto-affiliate
python main.py
```

## Features
- **Live Amazon Scraper:** Searches Amazon via SerpAPI with associate tag `smartdeal0358-21`.
- **Free FLUX AI Generator:** Renders vertical photorealistic room setups via Pollinations AI.
- **Aesthetic Typography:** Overlays top golden pill badges and Playfair Display serif headline cards.
- **SEO Copywriting:** Uses Gemini 2.0 Flash to generate high-CTR titles and keyword-rich descriptions.
- **Bridge Pages:** Generates responsive dark-mode landing pages with Amazon mobile app deep-linking.
