1. EXECUTIVE OVERVIEW & CORE MISSION
================================================================================
This platform is an automated, high-converting affiliate marketing and multi-region 
e-commerce ecosystem. It converts visual traffic from Pinterest into Amazon Associate 
affiliate commissions with a 100% Zero 404-Error Guarantee across international 
Amazon marketplaces using Amazon OneLink and direct local store fallback routing.

Core Platform Pillars:
  1. 100% User-Directed Publishing: Complies strictly with Pinterest API v5 Guidelines.
  2. 8K AI Image Generation: Uses Replicate Flux Dev AI model to turn product photos 
     into commercial lifestyle room scenes.
  3. Playwright Price Badge Overlay: Renders custom graphic price badges on top of 
     generated AI visuals.
  4. Authoritative Network-First Geo Engine: Uses Cloudflare trace and cascading IP 
     APIs with a 1.5-second fallback deadline and single-resolution guard (`commitResolution`).
  5. Amazon OneLink Integration: Preserves canonical Amazon.com URLs (`smartdeal0358-20`) 
     for OneLink countries (US, CA, UK/GB, DE, FR, IT, ES), letting Amazon servers execute 
     seamless regional store routing.
  6. Verified vs Unverified Pricing Engine: Displays `✨ VERIFIED DEAL` strictly when 
     a direct regional ASIN is verified, and labels reseller/import prices as 
     `⚠️ UNLISTED IN REGION • Approx. [price]`.
  7. Geo-Aware Shipping & Prime Messaging: Displays `⚡ Prime 2-Day Free Shipping` for 
     US visitors, `📦 Amazon OneLink International Delivery` for OneLink countries, 
     `📦 Amazon India Delivery Available` for direct India listings, and 
     `📦 US Import • Search Amazon.in Deals` for search fallbacks.

File: fixed_n8n_workflow.json

4. GEO-ROUTING ENGINE, ONELINK & AFFILIATE TAG COMPLIANCE
================================================================================

--------------------------------------------------------------------------------
AUTHORITATIVE NETWORK-FIRST GEO ENGINE (bridge_{ASIN}.html)
--------------------------------------------------------------------------------
When a visitor lands on a bridge page from Pinterest, our embedded JavaScript geo-engine 
executes dynamically:

  1. Network IP Geo Detection (PRIMARY):
     - Fetches `https://www.cloudflare.com/cdn-cgi/trace` and fallback IP APIs.
     - Network IP result is strictly authoritative when it returns a valid country code.

  2. 1.5-Second Fallback Deadline Timer:
     - Sets a 1500ms timeout deadline. Timezone and language signals are evaluated 
       ONLY if network requests fail or time out.

  3. Single-Resolution Guard (`commitResolution`):
     - Prevents race conditions and guarantees that exactly ONE country decision is 
       committed per page load. Late network callbacks cannot overwrite a committed state.

--------------------------------------------------------------------------------
AMAZON ONELINK & INDIA ROUTING RULES
--------------------------------------------------------------------------------
  - OneLink Countries (US, CA, GB/UK, DE, FR, IT, ES):
    Preserves canonical URL: https://www.amazon.com/dp/{ASIN}?tag=smartdeal0358-20
    Amazon OneLink handles server-side store redirection on Amazon servers.

  - India Direct Listing (Verified Direct ASIN in regional_asins):
    CTA: https://www.amazon.in/dp/{IN_ASIN}?tag=smartdeal0358-21
    Badge: 📦 Amazon India Delivery Available
    Tag: ✨ VERIFIED DEAL • ₹[Price]

  - India Search Fallback (No Direct ASIN in regional_asins):
    CTA: https://www.amazon.in/s?k={keywords}&tag=smartdeal0358-21
    Badge: 📦 US Import • Search Amazon.in Deals
    Tag: ⚠️ UNLISTED IN REGION • Approx. ₹[Price]
    Banner: Item Ships from Amazon US (Not Directly Listed on amazon.in)

--------------------------------------------------------------------------------
ASSOCIATE TAG ISOLATION GUARANTEE
--------------------------------------------------------------------------------
  - smartdeal0358-20 : Used EXCLUSIVELY for US/OneLink canonical URLs on amazon.com.
  - smartdeal0358-21 : Used EXCLUSIVELY for Amazon India URLs on amazon.in.
  - Zero tag cross-contamination exists across Python code, JSON configs, n8n, or HTML.

5. VERIFIED VS UNVERIFIED PRICING & SHIPPING MESSAGING
================================================================================

--------------------------------------------------------------------------------
VERIFIED PRICE LABELING RULE
--------------------------------------------------------------------------------
A price is labeled `✨ VERIFIED DEAL` ONLY when `isDirectListing === true` (verified 
regional ASIN or US source listing). Unlisted reseller import prices or search fallbacks 
are labeled `⚠️ UNLISTED IN REGION • Approx. [price]`. Real-time exchange rate conversions 
are explicitly prefixed with `Approx.`.

--------------------------------------------------------------------------------
GEO-AWARE SHIPPING BADGES
--------------------------------------------------------------------------------
  - US Visitors (`targetCC === 'US'`): ⚡ Prime 2-Day Free Shipping
  - OneLink Visitors (`CA`, `GB`, `UK`, `DE`, `FR`, `IT`, `ES`): 📦 Amazon OneLink International Delivery
  - India Direct Listing (`IN` + direct ASIN): 📦 Amazon India Delivery Available
  - India Search Fallback (`IN` + unlisted ASIN): 📦 US Import • Search Amazon.in Deals
  - Other / Unknown Countries: 📦 Amazon Global Delivery
