1. EXECUTIVE OVERVIEW & CORE MISSION
================================================================================
This platform is an automated, high-converting affiliate marketing and multi-region 
e-commerce ecosystem. It converts visual traffic from Pinterest into Amazon Associate 
affiliate commissions with a 100% Zero 404-Error Guarantee across international 
Amazon marketplaces using Amazon OneLink and direct local store fallback routing.

Core Platform Pillars:
  1. 100% User-Directed Publishing: Complies strictly with Pinterest API v5 Guidelines.
  2. 8K AI Image Generation: Uses Replicate Flux Dev AI model to turn product photos 
     into commercial lifestyle room scenes.
  3. Playwright Price Badge Overlay: Renders custom graphic price badges on top of 
     generated AI visuals.
  4. Authoritative Network-First Geo Engine: Uses Cloudflare trace and cascading IP 
     APIs with a 1.5-second fallback deadline and single-resolution guard (`commitResolution`).
  5. Amazon OneLink Integration: Preserves canonical Amazon.com URLs (`smartdeal0358-20`) 
     for OneLink countries (US, CA, UK/GB, DE, FR, IT, ES), letting Amazon servers execute 
     seamless regional store routing.
  6. Verified vs Unverified Pricing Engine: Displays `✨ VERIFIED DEAL` strictly when 
     a direct regional ASIN is verified, and labels reseller/import prices as 
     `⚠️ UNLISTED IN REGION • Approx. [price]`.
  7. Geo-Aware Shipping & Prime Messaging: Displays `⚡ Prime 2-Day Free Shipping` for 
     US visitors, `📦 Amazon OneLink International Delivery` for OneLink countries, 
     `📦 Amazon India Delivery Available` for direct India listings, and 
     `📦 US Import • Search Amazon.in Deals` for search fallbacks.

4. AUTHORITATIVE NETWORK-FIRST GEO ENGINE & ROUTING MECHANICS
================================================================================

--------------------------------------------------------------------------------
CLIENT-SIDE GEO DETECTION ARCHITECTURE (bridge_{ASIN}.html)
--------------------------------------------------------------------------------
When an international visitor opens any bridge landing page, our embedded client-side 
JavaScript engine executes dynamic geo-resolution:

  1. Network IP Geo Detection (PRIMARY AUTHORITATIVE SOURCE):
     - Initiates an immediate fetch to `https://www.cloudflare.com/cdn-cgi/trace`.
     - Cascades to secondary IP APIs (`ipwho.is`, `freeipapi.com`, `api.country.is`, `ipapi.co`) 
       if Cloudflare trace fails.
     - The Network IP response is strictly authoritative when it returns a valid 2-letter 
       country code.

  2. 1.5-Second Fallback Deadline Timer:
     - Sets a 1500ms deadline (`setTimeout(..., 1500)`).
     - Passive timezone (`Intl.DateTimeFormat`) and browser language (`navigator.language`) 
       detection runs ONLY if network requests time out or fail.
     - Timezone/language signals NEVER execute synchronously on page load to commit 
       affiliate URLs.

  3. Single-Resolution Guard (`commitResolution`):
     - `let isResolved = false` lock guarantees that exactly ONE country decision is 
       committed per page view.
     - Once resolution is committed, late network callbacks or fallback timers are 
       ignored, eliminating race conditions.

  4. Safe Default Href Protection:
     - The CTA button `href` remains locked to the canonical OneLink URL 
       (`https://www.amazon.com/dp/{ASIN}?tag=smartdeal0358-20`) until `commitResolution()` 
       executes and applies target routing.

--------------------------------------------------------------------------------
ONELINK MARKETPLACE ROUTING (US, CA, UK/GB, DE, FR, IT, ES)
--------------------------------------------------------------------------------
For visitors from Amazon OneLink enabled countries (United States, Canada, United Kingdom, 
Germany, France, Italy, Spain):

  - Amazon OneLink (enabled on the Amazon Associate Console for tag `smartdeal0358-20`) 
    detects the visitor's local IP on Amazon servers and redirects them to their local store 
    (e.g., amazon.co.uk or amazon.de) while preserving affiliate attribution.

INDIA DIRECT VS SEARCH FALLBACK ROUTING
--------------------------------------------------------------------------------
For visitors from India (`IN`):
  - Case A: Verified Direct Listing (`regional_asins['IN']` exists):
    CTA URL: `https://www.amazon.in/dp/{IN_ASIN}?tag=smartdeal0358-21`
    Button Text: `BUY ON AMAZON INDIA (₹)`
    Badge: `📦 Amazon India Delivery Available`
    Tag Label: `✨ VERIFIED DEAL • ₹[Price]`

  - Case B: Search Fallback (`regional_asins['IN']` missing):
    CTA URL: `https://www.amazon.in/s?k={keywords}&tag=smartdeal0358-21`
    Button Text: `SEARCH LOCAL DEALS ON AMAZON INDIA (₹)`
    Badge: `📦 US Import • Search Amazon.in Deals`
    Tag Label: `⚠️ UNLISTED IN REGION • Approx. ₹[Price]`

--------------------------------------------------------------------------------
ASSOCIATE TAG ISOLATION GUARANTEE
--------------------------------------------------------------------------------
  - `smartdeal0358-20` : Used EXCLUSIVELY for canonical US/OneLink URLs on `amazon.com`.
  - `smartdeal0358-21` : Used EXCLUSIVELY for Amazon India URLs on `amazon.in`.

6. VERIFIED VS UNVERIFIED PRICING ENGINE
================================================================================

--------------------------------------------------------------------------------
VERIFIED PRICE LABELING RULE
--------------------------------------------------------------------------------
A price is labeled `✨ VERIFIED DEAL` ONLY when `isDirectListing === true` (verified 
regional ASIN mapping or US canonical source listing). 

If `isDirectListing === false` (e.g. reseller import price, keyword search fallback), 
the price tag is NEVER presented as a verified deal. It is explicitly labeled:
`⚠️ UNLISTED IN REGION • Approx. [price]`

--------------------------------------------------------------------------------
EXCHANGE RATE CURRENCY CONVERSION
--------------------------------------------------------------------------------
  - Real-time exchange rates fetched from Open Exchange Rates API 
    (`https://open.er-api.com/v6/latest/USD`).
  - Converted regional prices without a direct listing are explicitly prefixed as `Approx.`:
    Example: `Approx. ₹7,096.67` or `Approx. £66.29` or `Approx. kr289,99`.
