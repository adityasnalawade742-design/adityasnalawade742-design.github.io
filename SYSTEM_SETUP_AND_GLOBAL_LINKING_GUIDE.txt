1. EXECUTIVE OVERVIEW & CORE MISSION
================================================================================
This platform is an automated, high-converting affiliate marketing and multi-region 
e-commerce ecosystem. It converts visual traffic from Pinterest into Amazon Associate 
affiliate commissions with a 100% Zero 404-Error Guarantee across 21 international 
Amazon marketplaces.

Core Platform Pillars:
  1. 100% User-Directed Publishing: Complies with Pinterest API v5 Guidelines.
  2. 8K AI Image Generation: Uses Replicate Flux Dev AI model to turn product photos 
     into commercial lifestyle room scenes.
  3. Playwright Price Badge Overlay: Renders custom graphic price badges on top of 
     generated AI visuals.
  4. 21-Domain Regional Geo Matrix: Automatically routes global visitors to their native 
     local Amazon store (e.g., amazon.in for India, amazon.co.uk for UK, amazon.de for 
     Germany, amazon.ca for Canada, etc.) carrying official Associate Tag IDs.
  5. 45-World Currency Engine: Automatically converts product prices into the visitor's 
     local currency using real-time open exchange rates.

      * /api/sync_prices : Triggers master 21-domain regional price sync.
      * /api/matrix : Returns global direct matrix state for all active ASINs.

LAYER 3: N8N 8-NODE AUTOMATION WORKFLOW
--------------------------------------------------------------------------------
File: fixed_n8n_workflow.json
Pipeline Breakdown:
  Node 1 : Webhook — Receives incoming batch payload from Web Console.
  Node 1b: Respond — Returns HTTP 200 JSON acknowledgment to Web Console immediately.
  Node 2 : Split Items — Processes batch products sequentially one by one.
  Node 3 : Code in JS — Clamps titles to max 35 characters, sanitizes price format.
  Node 4 : Classifier — Evaluates white cutout vs room photo to select AI prompt.
  Node 4a/b: Set Prompt — Injects Prompt A (0.78 strength) or Prompt B (0.50 strength).
  Node 5 : Replicate API — Calls Black Forest Labs Flux Dev model synchronously.
  Node 6 : Build Bridge — Calls Web Console server (/api/create_bridge_page) to render 
           Playwright price badge overlay and build luxury landing page.
  Node 7 : Post Pin — Submits Pin payload to Pinterest API v5 (supports both Production 
           URL and Sandbox Trial Mode using Base64 inline image uploads).
  Node 8 : Log Result — Records Pin publishing status and Pin ID.

    to Pinterest API v5.
  - Pin goes live on your target Pinterest board.

4. 21-DOMAIN INTERNATIONAL GEO MATRIX & GLOBAL LINKING MECHANICS
================================================================================

--------------------------------------------------------------------------------
THE PROBLEM WITH STANDARD AFFILIATE LINKS
--------------------------------------------------------------------------------
If an international visitor from India, UK, or Germany clicks a standard US Amazon link 
(amazon.com/dp/ASIN):
  1. Amazon US charges high international shipping fees and import duties (causing 95%+ 
     visitor bounce rate).
  2. If that specific ASIN is not listed in Amazon US, the visitor gets Amazon's 
     infamous 404 "Looking for something? We're sorry" dog error page.

--------------------------------------------------------------------------------
OUR SOLUTION: 0MS CLIENT-SIDE GEO-REDIRECTOR (bridge_{ASIN}.html)
--------------------------------------------------------------------------------
Every Pin published on Pinterest links back to a dedicated luxury landing page:
  https://adityasnalawade742-design.github.io/bridge_{ASIN}.html

When an international visitor opens this page, our embedded JavaScript geo-engine 
executes instantly in 0 milliseconds:

  1. Country Detection:
     - Checks URL parameter first (e.g., ?country=IN or ?country=UK).
     - If omitted, inspects browser timezone (Intl.DateTimeFormat) and IP geolocation 
       service (ipapi.co).
     - Resolves 2-letter country code (US, IN, GB, DE, CA, FR, ES, IT, SE, NL, PL, TR, 
       BE, JP, AU, MX, BR, SG, AE, SA, EG).

  2. Matrix Lookup (global_direct_matrix.json):
     - The system checks if the exact product ASIN has been empirically verified to exist 
       in that country's local Amazon catalog.

  3. Routing Execution:
     - Direct ASIN Match (YES): Redirects visitor directly to local product page:
       Example: https://www.amazon.in/dp/B0BZXNSW5K?tag=smartdeal0358-21
     - Targeted Search Fallback (NO): Redirects visitor to local category search results:
       Example: https://www.amazon.in/s?k=Touch+Bedside+Lamp&tag=smartdeal0358-21
